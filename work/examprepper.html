ExamPrepper

Build practice exams from five question types, then sit them as practice tests.

Study tool · 2023 · Open source · github.com/RoyaleNite/ExamPrepper

Five kinds of question, one practice exam.

What it does

  • Five question types

    Open questions, multiple choice, true or false, fill in the blank, and match the columns.

  • Subjects and collections

    Group questions by subject and put them together as an exam or a quick quiz.

  • Sit a test

    One question at a time, back and forth, with results at the end.

  • No database

    Everything is saved as JSON files next to the app.

How it's made

A study project in C# and Windows Forms on .NET 7, written to turn notes into practice tests. It is unfinished, and the code is open on GitHub.

  • C#
  • .NET 7
  • Windows Forms
  • JSON
