# royalenite.github.io

The portfolio of Waldre Roos, a freelance software developer in Mbombela, South Africa: **[royalenite.github.io](https://royalenite.github.io)**.

Plain HTML, CSS and a little JavaScript, served by GitHub Pages with no build step on the server.

- `build.py` writes every page from the content at its top: `python3 build.py`, then commit the HTML.
- `assets/site.css` and `assets/site.js` are the whole design and behaviour; the colours and serif match the [profile banner](https://github.com/RoyaleNite).
- Screenshots in `assets/img` come from the products' own demo data.
- Fonts: [Instrument Serif and Instrument Sans](https://github.com/Instrument/instrument-sans), SIL Open Font License (`assets/fonts/OFL.txt`).

To preview locally: `npx serve .` and open the address it prints.
