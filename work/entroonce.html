Entroonce

A Discord bot that plays each person's intro when they join a voice channel, set up from a page in the browser.

Discord bot · 2026 · Source-available (FSL-1.1-MIT)

What it does

  • Intros and outros

    When someone joins the voice channel, one of their intros plays; when they leave, their outro.

  • Fair turns

    Intros take turns, least played first, so a new one is heard next.

  • A setup page, not config files

    It checks the bot token with Discord, makes the invite link and lists your servers, roles and channels to pick from.

  • Clips from Seqwence

    Seqwence sends a cut clip to the bot with one button, after a one-time link.

  • Runs anywhere

    A Windows installer, Docker for a server, or systemd on Linux; everything lives in one data folder.

How it's made

Entroonce is written in Python. It runs without a token at first, serving its own setup page, and starts the Discord side once a token is saved.

  • Python
  • discord.py
  • aiohttp
  • SQLite
  • Docker
