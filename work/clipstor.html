Clipstor

Batch-trim, compress, convert and sort game recordings on Windows, without opening an editor.

Windows desktop tool · 2022 · Closed

A folder of clips, sorted by game and date.

What it does

  • A clip sorter

    Reads the file names NVIDIA and AMD recording software write, and sorts a folder into one per game, with an undo.

  • Batch renaming

    Rename a whole folder of clips to one pattern.

  • A clip viewer

    A table of every clip's details with generated thumbnails.

  • A trimmer and render queue

    Set in and out points while watching, add the trim to a queue, and let it render in order.

  • Export presets

    H.265 quality, resolution, threads, audio bitrate and per-track names, saved as presets.

How it's made

Clipstor is a Windows Forms app in C# on .NET Framework, with FFmpeg bundled for the encoding.

  • C#
  • .NET Framework 4.8
  • Windows Forms
  • FFmpeg
